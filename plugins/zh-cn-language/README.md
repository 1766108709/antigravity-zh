# 简体中文全局规则 (zh-cn-language)

这是一个全局自定义规则插件，用于在 Antigravity 中实现类似 Claude Code `"language": "简体中文"` 的全局语言约束效果。

## 生效范围
启用本插件后，Agent 在所有工作区和会话中都会默认使用**简体中文**输出：
1. **聊天回复与代码解析**
2. **模型提问卡片 (`ask_question`)**：问题标题与候选项均为中文
3. **命令执行与授权摘要 (`run_command` -> `toolSummary`)**：授权审批卡片上的用途描述为中文
4. **文档与计划审批 (`Artifacts`)**：计划正文与审批摘要均为中文

## 如何修改或停用
- **临时停用/启用**：可在左侧 **Skills & Customizations（自定义）** 面板中找到 **简体中文全局规则** 直接开关，无需重启客户端。
- **自定义措辞**：编辑本目录下的 `rules/AGENTS.md` 文件即可实时更新规则内容。
